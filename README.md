# Fındık ile Pamuk

**Privacy Policy / Gizlilik Politikası:** [docs/GIZLILIK.md](docs/GIZLILIK.md) ·
**Terms of Service / Kullanım Koşulları:** [docs/KOSULLAR.md](docs/KOSULLAR.md)

This tool uses the **YouTube API Services** to upload the owner's own episodes to the owner's own YouTube
channel. [YouTube Terms of Service](https://www.youtube.com/t/terms) ·
[Google Privacy Policy](https://policies.google.com/privacy)

Çocuklar (3-7 yaş) için Türkçe, özgün 3D kısa çizgi film serisi ve onu üreten otomasyon.
Her bölüm tek bir değer işler (paylaşmak, dürüstlük, özür dilemek, sabır...).

- Karakterler, mekânlar, müzik ve efektler koddan üretilir (Blender + Python); telifli içerik yoktur.
- Senaryolar `seri/findik-ile-pamuk/bolumler/` altındadır ve elle yazılmıştır.
- Üretim GitHub Actions'ta çalışır (`.github/workflows/gunluk3d.yml`); her video yayından önce
  otomatik kalite kontrolünden geçer (süre, ses, altyazı, siyah/donuk kare, dudak senkronu,
  karakter tutarlılığı). Geçmeyen video yayımlanmaz.
- Videolar YouTube'da "Çocuklar için yapılmış" olarak işaretlenir.

Ayrıntılar: [docs/3D-STUDYO.md](docs/3D-STUDYO.md) · Kurulum: [docs/YOUTUBE-KURULUM.md](docs/YOUTUBE-KURULUM.md)

Seslendirme: Microsoft Edge çevrimiçi metin-okuma servisi (edge-tts). Yazı tipi: Baloo 2 (OFL).
2D figürler: Google Noto Emoji (Apache 2.0 / OFL).
