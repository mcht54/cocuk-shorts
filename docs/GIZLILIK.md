# Privacy Policy / Gizlilik Politikası — Findik ile Pamuk Yukleyici

Last updated / Son güncelleme: 27 October 2026

## English

"Findik ile Pamuk Yukleyici" is a single-user tool. Its only function is to upload the owner's own original
animated episodes to **the owner's own YouTube channel**.

**Use of YouTube API Services.** This tool uses the YouTube API Services. By using it you agree to be bound by
the **YouTube Terms of Service**: https://www.youtube.com/t/terms
Google's privacy practices apply to data processed by YouTube: **Google Privacy Policy**:
https://policies.google.com/privacy

**Data we access.** Only the OAuth scope `https://www.googleapis.com/auth/youtube.upload` is requested, solely to
upload videos to the authorizing user's own channel. The tool does not read, collect or store any YouTube user
data, viewer data, comments, analytics or personal information, and uses no cookies or tracking.

**Data we store.** Only the ID and upload date of each video uploaded by the tool are kept in the project
repository file `yayin_kaydi.json`. OAuth credentials are stored encrypted in GitHub Actions Secrets and are
never shared.

**Sharing.** No data is shared with, sold to, or disclosed to any third party.

**Children.** Uploaded content is directed to children and is marked "Made for Kids" on YouTube. The tool collects
no data from children or anyone else.

**Revoking access and deleting data.** Access can be revoked at any time via the Google security settings page:
https://myaccount.google.com/permissions . After revocation the stored credentials stop working and are deleted
from GitHub Secrets on request; the stored video IDs can be deleted on request. Contact:
https://github.com/mcht54/cocuk-shorts/issues (response within 7 days).

## Türkçe

"Findik ile Pamuk Yukleyici", kanal sahibinin kendi ürettiği özgün çizgi film bölümlerini **yalnızca kendi
YouTube kanalına** yükleyen tek kullanıcılı bir araçtır.

- **YouTube API Hizmetleri:** Araç YouTube API Hizmetleri'ni kullanır; kullanım **YouTube Hizmet Şartları**na
  (https://www.youtube.com/t/terms) tabidir. **Google Gizlilik Politikası**: https://policies.google.com/privacy
- **Erişilen veri:** Yalnız `youtube.upload` yetkisi; amaç yalnız kendi kanalına video yüklemek. Hiçbir kişisel
  veri, izleyici verisi, yorum, istatistik ya da çerez toplanmaz.
- **Saklanan bilgi:** Yalnız yüklenen videonun kimliği ve tarihi (`yayin_kaydi.json`). Erişim anahtarları
  GitHub'ın şifreli gizli kasasında tutulur, kimseyle paylaşılmaz.
- **Üçüncü taraflarla paylaşım:** Yok.
- **Çocuklar:** İçerik çocuklara yöneliktir, YouTube'da "Çocuklar için yapıldı" işaretlenir; veri toplanmaz.
- **İzni geri alma ve silme:** https://myaccount.google.com/permissions adresinden izin her an geri alınabilir;
  talep üzerine anahtarlar ve kayıtlı video kimlikleri silinir. İletişim:
  https://github.com/mcht54/cocuk-shorts/issues (7 gün içinde yanıt).
